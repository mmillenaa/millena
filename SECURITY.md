# Security Policy

## Context
This repository hosts a static personal website and academic portfolio deployed via GitHub Pages. There is no backend server, database, or user data collection involved. The realistic security risks are confined to potential vulnerabilities in third-party scripts or static site generation plugins (e.g., Jekyll).

## Supported Versions
Only the latest version on the `main` branch is actively maintained and updated.

## Reporting a Vulnerability
If you discover a security issue, please do not open a public issue. Report it privately using one of the following methods:

1. **GitHub Private Reporting:** Go to the Security tab → Report a vulnerability.
2. **Email:** Send a message directly to millena@usp.br.

You will receive an acknowledgment within ten working days.
